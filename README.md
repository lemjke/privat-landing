# Привал — лендинг проката туристического снаряжения

Демо-проект для портфолио: одностраничный сайт вымышленного проката снаряжения в Новосибирске.
Сделан с помощью AI-агента **Claude Code** (вайбкодинг): постановка задачи, дизайн-решения, ревью и проверка результата — мои, код писал агент под моим руководством.

**Демо:** https://lemjke.github.io/privat-landing/ <!-- заменить после публикации -->

## Что внутри

- **Адаптивная вёрстка** — от 360 px до широких экранов, отдельная мобильная панель корзины.
- **Каталог с фильтрами** по категориям, данные рендерятся из JS.
- **Калькулятор аренды** — количество вещей, срок (1–14 дней), скидки 10% от 3 дней и 20% от 7 дней, подсказка «ещё N дней до скидки».
- **Готовые наборы** — одним кликом добавляют комплект в корзину.
- **Форма заявки** — маска телефона, проверка полей и даты, экран подтверждения с итогом заказа.
- Корзина сохраняется в `localStorage`, анимации появления учитывают `prefers-reduced-motion`.
- Иллюстрации и иконки — инлайн-SVG, без картинок и сторонних библиотек.

## Стек

HTML, CSS (Grid, Flexbox, custom properties), ванильный JavaScript. Шрифты — Unbounded и Manrope (Google Fonts).

## Запуск

Открыть `index.html` в браузере или поднять любой статический сервер:

```bash
python -m http.server 8090
```

> «Привал» — вымышленный бренд, заявки никуда не отправляются.
